## 📐 Overlay Specification

### Gradient Details
```css
background: linear-gradient(
  to right,
  from #0a1b3d at 98% opacity,    /* Deep navy - darkest */
  via #0a1b3d at 85% opacity,     /* Smooth transition */
  via at 30%,                     /* Middle fade point */
  to transparent at 45%           /* Fully transparent */
)
```

## 🔧 Technical Implementation

### CSS Tailwind Classes
```javascript
className="bg-gradient-to-r 
           from-[#0a1b3d]/98 
           via-[#0a1b3d]/85 
           via-30% 
           to-transparent 
           to-45%"
```

### Breakdown
- `bg-gradient-to-r`: Left to right gradient
- `from-[#0a1b3d]/98`: Start color at 98% opacity
- `via-[#0a1b3d]/85`: Middle color at 85% opacity
- `via-30%`: Transition point at 30% width
- `to-transparent`: End fully transparent
- `to-45%`: Gradient stops at 45% width
